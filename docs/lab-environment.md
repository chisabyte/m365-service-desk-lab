# Lab Environment

Harbour Street Partners is a fictional Australian professional-services firm used as the setting for a personal Microsoft 365 support lab. Priya Nair, Maya Chen, Owen Blake and Alex Romero are synthetic users. The tickets describe staged incidents or service requests, not customer work or production employment. No production customer information or real company infrastructure is represented here.

The evidence in this repository shows administration and user checks in Microsoft 365 Business Basic, Microsoft Entra ID, Exchange Online, Outlook, Microsoft Teams, SharePoint and OneDrive. HSP-1002 also uses Microsoft Authenticator and Entra sign-in information.

The purpose is to practise a support sequence: understand the request, investigate the relevant state, make a scoped change, verify the outcome and document its limits. Screenshots were copied from the lab into this repository after review; some copies have additional name redactions. The original source evidence is kept outside the repository.
